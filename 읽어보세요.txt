3D 사무실 - 다른 컴퓨터에서 시작하기
========================================

클로드 코드로 작업하는 모든 세션(채팅창)이 브라우저 속 3D 사무실의
직원 캐릭터로 나타납니다. 일하면 타자를 치고, 답변 문장이 말풍선으로
뜨고, 캐릭터를 클릭하면 그 세션의 대화(지시 · 답변 · 사고 과정)를
실시간 채팅으로 볼 수 있습니다. 모든 통신은 이 컴퓨터 안(127.0.0.1)
에서만 돌고 밖으로 나가지 않습니다.

■ 준비물
- Windows + 클로드 코드(Claude Code)가 설치되어 있을 것
- Node.js LTS (없으면 https://nodejs.org 에서 LTS 설치)
- 클로드 코드는 2.1.280 이상이어야 Opus 5.5 · Fable 5.1 모델을 고를 수 있다(`claude update`)

■ 설치
1. https://github.com/sheahe0220/3d-office-share/releases/latest 에서
   3d-office_<판>.zip 을 받는다.
2. 압축을 원하는 곳(예: 문서)에 푼다. "3D 사무실" 폴더가 생긴다.
3. 그 안의 설치.cmd 를 두 번 클릭한다. (파란 경고가 뜨면 "추가 정보" -> "실행")
   훅 등록 · 바탕화면 바로 가기 · 브라우저 열기까지 한다.
4. 이후에는 바탕화면의 "3D 사무실" 바로 가기로 연다.

■ 클로드 토큰 최적화 (클로드_최적화 폴더)
Pro 요금제에서 쓸데없이 새는 토큰을 막는 지침과 안내를 같이 넣어 두었다.
- 클로드 코드에 "클로드_최적화\클로드코드에_적용요청.md 파일대로 적용해 줘" 라고 하면
  모든 세션에 적용되는 전역 지침으로 넣어 준다(기존 지침은 백업하고 그대로 둔다).
- 채팅(claude.ai · 데스크톱 앱)용 문구와 습관 안내: 클로드_최적화\00_먼저읽기.md
- 3D 사무실의 웹 대화 · 회의실은 설정(⚙)의 "토큰 최적화" 가 처음부터 켜져 있다.

■ 자동 업데이트
바로 가기로 켤 때마다 새 판이 있는지 확인하고, 있으면 바뀐 파일만 받아서 바꾼 뒤 연다.
따로 할 일은 없다. 이미 켜져 있어도 바로 가기로 다시 열면 새 판으로 바꿔 다시 켠다.
받은 파일은 하나하나 SHA256 으로 확인하고, 하나라도 어긋나면 아무것도 바꾸지 않는다.
- 기록: 업데이트.log
- 새 판이 이상하면 되돌리기(PowerShell 에서 이 폴더로 이동한 뒤):
    node 도구\업데이트.js --rollback
  (바꾸기 전 판은 _이전판\ 에 최근 3 개까지 남는다)

설치기가 하는 일: 클로드 코드에 훅(이벤트 알림) 등록, 바탕화면
바로 가기 생성, 뷰어 실행. 다시 실행해도 안전하다(중복 없음).
클로드 설정 파일이 깨져 있으면 건드리지 않고 멈추며, 기존의 다른
훅은 보존하고, 처음 고치기 전 1회 백업을 남긴다.

■ 사용법
- 사용설명서: 위 표시줄의 "❓ 사용설명서" (또는 키보드 ? 키). 기능 13 가지를 그림과
  번호 순서로 설명한다. 아래 내용보다 자세하다.
- 화면 언어: 기본 한국어 (설정 톱니에서 영어 · 일본어 선택 가능)
- 캐릭터 클릭 -> 오른쪽 아래 "대화 보기" -> 대화 패널
- 사고 과정(💭)은 접혀 있고 누르면 펴진다
- 세션마다 캐릭터가 따로 생기고 각자 자기 대화만 보여 준다
- 상단 사용량 칸: 클로드 코드의 세션(5시간) · 주간 · 모델 한도 % 와 초기화까지
  남은 시간. 1분마다 갱신. 칸을 누르면 정확한 초기화 시각. 요금 표찰을 누르면
  분석 패널, Hook 표찰을 누르면 훅 상태(포트 · 마지막 수신).
- 웹 대화(왼쪽 아래 💬): 브라우저에서 클로드와 직접 대화. "웹 비서" 캐릭터가
  출근해 답한다. 서버를 껐다 켜도 이어진다. 작업 폴더와 모델을 고를 수 있다.
  ※ 주의: 웹 대화는 전체 도구 허용이라, 여기서 보낸 지시는 확인 없이 파일 수정과
  명령 실행으로 이어진다. 서버는 이 컴퓨터(127.0.0.1) 안에서만 열린다.

■ 제거
PowerShell 에서:  node 도구\훅제거.js
그리고 바탕화면 바로 가기와 이 폴더를 지우면 끝.

■ 문제가 생기면
- 화면이 안 열림: 실행.ps1 을 다시 실행. 그래도 안 되면 브라우저
  주소창에 127.0.0.1:3100
- 캐릭터가 안 생김: 설치.ps1 을 다시 실행(훅 재등록) 후, 클로드
  코드에서 아무 명령이나 한 번 실행
- 업데이트가 안 됨: 업데이트.log 의 마지막 줄을 캡처해서 보내 준다.
