# 클로드 코드에게: 토큰 최적화 지침을 모든 세션에 적용해 주세요

이 파일을 클로드 코드에 주고 "이 파일대로 적용해 줘" 라고 하면 됩니다.

## 클로드 코드가 할 일

1. 사용자 전역 지침 파일 `~/.claude/CLAUDE.md` (Windows 는 `%USERPROFILE%\.claude\CLAUDE.md`)를 연다. 없으면 새로 만든다.
2. 파일이 이미 있으면 먼저 같은 폴더에 `CLAUDE.md.백업_YYYYMMDD_HHMM` 으로 복사해 둔다.
3. 파일 안에 `<!-- 토큰 최적화 지침 시작 -->` 표시가 이미 있으면, 그 표시부터 `<!-- 토큰 최적화 지침 끝 -->` 까지를 아래 "지침" 절로 바꾼다. 없으면 파일 끝에 아래 "지침" 절을 두 표시와 함께 붙인다. 이미 있는 다른 내용은 건드리지 않는다.
4. 다 했으면 한 줄로 알린다: 어느 파일에 넣었는지, 백업 파일 이름, 새로 넣었는지 바꿨는지.
5. 마지막으로 아래 "채팅용 문구" 를 그대로 보여 주고, claude.ai 와 데스크톱 앱의 설정 > 프로필 > 개인 선호 칸에 직접 붙여 넣으라고 안내한다. 이것은 클로드 코드가 대신 넣을 수 없다.

## 효율 지침 (요청마다 함께 읽히므로 짧게 유지)

- 결론부터 쓴다. 단순한 질문은 1-3 문장으로 답한다.
- 요청받은 범위만 한다. 묻지 않은 설명, 리팩터링, 대안 나열, 요약 반복을 하지 않는다.
- 같은 내용을 다시 확인하거나 되풀이하지 않는다.
- 정보가 모자라면 추측으로 길게 진행하지 말고, 필요한 질문을 한 번에 묶어 묻는다.
- 파일을 통째로 읽기 전에 검색으로 필요한 곳을 찾고, 그 부분만 읽는다. 같은 파일을 여러 번 읽지 않는다.
- 긴 출력(로그, 시험 결과)은 필요한 줄만 걸러서 본다.
- 도구는 꼭 필요할 때만 쓴다.
- 계획은 짧게 세우고 바로 실행한다. 단계가 끝날 때마다 한 줄로 알린다.

## 채팅용 문구

```text
결론부터 짧게 답해 주세요. 간단한 질문은 1-3 문장이면 충분합니다.
제가 묻지 않은 배경 설명, 대안 나열, 마지막 요약은 빼 주세요.
코드는 바뀐 부분만 보여 주고, 전체가 필요할 때만 전체를 주세요.
정보가 모자라면 추측해서 길게 쓰지 말고 필요한 질문을 한 번에 물어봐 주세요.
```

## 사람이 기억해 둘 습관

자세한 이유와 출처는 같은 폴더의 `00_먼저읽기.md` 에 있습니다.

- 주제가 바뀌면 새 대화(클로드 코드는 `/clear`)로 시작한다.
- 대화 중간에 모델을 바꾸지 않는다(캐시가 깨진다).
- 같은 문서를 자주 쓰면 claude.ai 프로젝트 지식에 올린다.
- 안 쓰는 MCP 서버 · 연결 앱 · 웹 검색 · 확장 사고는 끈다.
