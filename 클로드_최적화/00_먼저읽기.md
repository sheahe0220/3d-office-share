# 클로드 토큰 최적화 안내

Pro 요금제는 5 시간 한도와 주간 한도를 claude.ai(웹), 데스크톱 앱, 클로드 코드가 함께 씁니다.
답의 질은 그대로 두고, 쓸데없이 새는 토큰만 막는 방법을 모았습니다.
근거는 끝의 출처에 있고, 모두 2026-09-28 에 확인했습니다.

## 1. 한 번만 해 두면 되는 설정

| 어디 | 무엇을 | 파일 |
|---|---|---|
| claude.ai 와 데스크톱 앱 | 설정 > 프로필의 "개인 선호" 칸에 붙여 넣기 | `채팅_개인선호.txt` |
| claude.ai 프로젝트 | 프로젝트 지침 칸에 붙여 넣기 | `프로젝트_지침.txt` |
| 클로드 코드 | `%USERPROFILE%\.claude\CLAUDE.md` 로 복사(이미 있으면 내용을 끝에 붙이기) | `CLAUDE.md` |

`CLAUDE.md` 는 클로드 코드가 요청할 때마다 같이 보내는 파일입니다. 여기에 긴 글을 쌓으면 그만큼 매번 토큰이 듭니다.
그래서 이 파일은 일부러 짧게 만들었습니다. 덧붙일 때도 짧게 유지하세요.

## 2. 채팅(웹 · 데스크톱)에서

- **주제가 바뀌면 새 대화를 엽니다.** 긴 대화는 한도에 가까워질수록 더 많이 씁니다. 공식 안내가 긴 대화에서는 새 대화를 시작하라고 권합니다.
- **같은 문서를 자주 쓰면 프로젝트 지식에 올립니다.** 프로젝트에 올린 문서는 캐시되어, 새로 붙이는 내용보다 한도에 덜 잡힙니다(공식 안내).
- **안 쓰는 연결 앱, 웹 검색, 확장 사고는 끕니다.** 최신 정보가 필요 없으면 웹 검색을 끄고, 깊게 생각할 문제가 아니면 확장 사고를 끕니다(공식 안내).
- **관련 질문은 한 번에 묶어서 묻고, 필요한 자료는 처음에 한 번에 줍니다.** 되묻는 왕복이 줄어듭니다(공식 안내).
- **모델은 일에 맞춥니다.** 간단한 질문이나 정리는 Sonnet, 어려운 설계나 긴 추론은 Opus 를 씁니다. 모델마다 한도를 쓰는 양이 다르다는 것까지는 공식이지만, 정확한 배율은 공개되지 않았습니다.

## 3. 클로드 코드에서

- **서로 관계없는 일은 `/clear` 로 새로 시작합니다.** 이전 대화 전체가 요청마다 다시 들어가기 때문입니다(공식 비용 문서).
- **대화 중간에 모델이나 사고 강도를 바꾸지 않습니다.** 바꾸면 캐시가 깨져 다음 요청이 비싸집니다. Opus 5.5 는 사고 강도를 바꿔도 캐시가 유지됩니다(공식 캐시 문서).
- **쉬었다가 이어 갈 때는 1 시간 안에 이어 갑니다.** 구독 사용량 안에서는 캐시가 1 시간 유지됩니다. `/compact` 는 캐시가 식은 뒤 돌리면 비쌉니다.
- **사고 강도는 기본값이면 충분합니다.** Opus 5.5 의 기본은 medium 이고, 공식 문서는 이것이 Opus 5 의 high 와 같거나 낫다고 합니다. max 는 지나치게 오래 생각하는 경향이 있다고 적혀 있습니다.
- **짧은 답을 원하면 `/output-style` 에서 concise 를 고릅니다.** 결론이 첫 문장에 오고 단순한 질문은 1-3 문장으로 답합니다(공식 문서, v2.1.269 이상).
- **안 쓰는 MCP 서버와 플러그인은 끕니다.** 켜 둔 것은 요청마다 설명이 따라붙습니다.
- **큰 로그나 파일은 필요한 부분만 보여 달라고 합니다.** "오류 줄만", "끝 50 줄만" 처럼 범위를 줍니다.

## 4. 효과가 작거나 오히려 손해인 것

- **원시인 말투처럼 극단적으로 짧게 쓰게 하기:** 광고는 65-75 % 절감이지만, 실측에서는 출력이 8.5 % 줄었을 뿐입니다(JetBrains, 2026-07).
- **"다시 한번 확인해" 같은 재검증 지시:** 토큰만 늘고 품질은 그대로라고 공식 프롬프트 안내에 적혀 있습니다.
- **사고를 끄면 아낀다는 생각:** Opus 5 는 사고를 켠 low 가 끈 상태보다 비슷한 비용에 더 낫고, Opus 5.5 는 사고를 끌 수 없습니다.

## 5. 3D 사무실 안에서

설정(⚙)의 "토큰 최적화" 가 친구 판에서는 처음부터 켜져 있습니다.
웹 대화와 회의실이 클로드를 부를 때, 쓰지 않는 MCP 서버와 스킬을 빼고 군더더기 없이 답하게 합니다.

| 호출 | 입력 토큰 | 출력 토큰 | 비용 추정 |
|---|---|---|---|
| 회의 발언 | 23,213 → 14,563 | 244 → 197 | $0.187 → $0.121 |
| 웹 대화 짧은 질문 | 153,139 → 116,461 | 764 → 534 | 첫 호출은 캐시를 새로 만들어 비슷함 |

같은 질문으로 이 앱을 만든 PC 에서 잰 값입니다(2026-09-28, 한 번씩). PC 마다 설치된 MCP 서버와 지침 크기가 달라 줄어드는 양은 달라집니다.
"이어서 지시하기" 에는 일부러 적용하지 않습니다. 원래 세션과 설정이 달라지면 캐시가 깨져 오히려 비싸지기 때문입니다.
